# dsh-purge

面向 Windows 本机 DSH NEXT（`0.2.2-rc.5`）深度精简与适配，集成全放行演练、上下文动态瘦身（安全段裁剪 / 运行时即改）、`0.2.2` 预设兼容、消息内容形态保护（`#100` / `#101`）、无损压缩会话记忆（`purge_memory`）、目标/证据守护与解包自愈能力（原作者：[YangYuHou](https://github.com/YangYuHou)）。
