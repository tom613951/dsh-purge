# dsh-purge (Fork)

本项目是基于 [YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge) 的定制维护分支，面向本地 DSH NEXT（`0.2.2-rc.1` / `rc.2`）精简与深度适配，集成全放行演练、上下文动态瘦身（安全段裁剪 / 运行时即改）、`0.2.2` 预设兼容与解包自愈能力。
